# T5 · Автономная навигация и ArUco

**Сдать до 27.11.2026, 12:00 МСК.** [Техническое задание (PDF)](spec.pdf)

**Сделано:** выписаны требования Nav2, протокол детекции и порядок тестов. Навигация, одометрия и детектор ещё не реализованы.

- Обязателен Nav2: Action-сервер `/navigate_to_pose`, TF `map → odom → trunk`, управляющий выход `/cmd_vel`. Использовать одометрию [T4](../T4/); скрытая карта не выдаётся, отдельного заезда для картографии нет.
- Распознавать словарь `DICT_4X4_50` по RGB-кадрам. В `/aruco/detections` (`std_msgs/msg/String`) отправлять текущие наблюдения в формате `{"ids":[3,7]}`, а не накопленный список. Сначала проверить фронтальную камеру, затем подключить ещё четыре.
- Прогнать публичную трассу шириной 2 м, затем 1 м. Проверять физическое достижение цели (ошибка ≤0,5 м и yaw ≤30°), отсутствие недопустимых контактов и долю реально видимых и распознанных меток. Статуса Nav2 `SUCCEEDED` недостаточно.
