- [ ] Nav2: action `/navigate_to_pose`, TF `map → odom → trunk`, выход `/cmd_vel`. Скрытой карты и отдельного картографического заезда нет.
- [ ] Детектор `DICT_4X4_50`: сперва фронтальная камера, потом остальные четыре. В `/aruco/detections` (`std_msgs/msg/String`) идут текущие наблюдения, например `{"ids":[3,7]}`. Не копим ID между кадрами.
- [ ] Трасса 2 м, затем 1 м. Цель считается по факту: ≤0,5 м и yaw ≤30°. Смотрим столкновения и долю распознанных меток. Одного `SUCCEEDED` мало.
