## Экспериментальный образ T2+T3

Из корня репозитория с Docker и экспортированными весами v3:

```bash
bash stages/T3/build_image.sh /path/to/actor-104857600.npz rh-participant:t3
docker run --rm --network none rh-participant:t3 ping
```

Скрипт проверяет SHA-256 весов и создаёт временный build context вне Git. Режим
`T3` запускает и safety, и политику; режим `T2` — только safety. Веса и логи
обучения хранятся отдельно; `self_trained_rl: true` в `ping` сам по себе не
подтверждает обучение. Публичный образ симулятора используется только как базовый
слой: entrypoint не запускает симулятор. Для локального rootless Podman из-за
ошибки слоёв использовалась уплощённая копия базы, что не доказывает стандартную
Docker-сборку.
