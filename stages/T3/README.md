# T3 / RL

**Дедлайн: 27.11.2026, 12:00 МСК.** [ТЗ (PDF)](spec.pdf)

Две серии: компактная PPO в локальном MuJoCo и [кандидаты команды в публичном симуляторе](https://github.com/tim1363/hackaton-EOL/blob/t2-t3-mishanya/stages/T3/TRAINING.md). Условия разные, цифры напрямую не сравниваем.

## MuJoCo benchmark

Актор на 7 884 параметра. По отчёту серии: 24 адаптивных прогона обучения, 16 повторов с другим seed. Кандидата выбрали по двум обучениям до финальной проверки.

Критерий локального теста: пройти 3 м без падения. Все варианты проверили на тех же 100 новых сценариях, из них 50 усложнённых.

| Контроллер | Прошёл | Среднее время на 3 м |
| --- | ---: | ---: |
| PPO | **100/100** | **7,99 с** |
| Ручная рысь, 1,4 Гц | 86/100 | Нет данных |
| Ручная рысь, 1,8 Гц | 71/100 | Нет данных |

PPO также прошла все **50/50** усложнённых заездов. Это не результат закрытого Judge. Веса `actor.npz`, чекпоинт `ppo.zip` и `report.json` этой серии хранятся вне Git.

## I/O

MuJoCo Lowlevel. Политика читает `/cmd_vel` и `/lowstate`, пишет в `/lowcmd_bare`. Только [T2 Safety](../T2/) пишет в `/lowcmd`.

## Что проверяем

- [ ] В публичном MuJoCo сравнить кандидатов на одних и тех же стартах и командах скорости. Для компактной PPO сверить входы, порядок 12 суставов и частоту инференса.
- [ ] Движение ≥3 м без падения: 1,5 с прогрева, до 90 с хода по sim time. Тестируем скорость 0,1-0,6 м/с и 10 независимых стартов.
- [ ] В образ положить веса и зависимости выбранной политики, в `ping` указать проверенную скорость. К `self_trained_rl` приложить веса, конфиг и журналы обучения.
