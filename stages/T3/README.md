# T3 / RL

**Дедлайн: 27.11.2026, 12:00 МСК.** [ТЗ (PDF)](spec.pdf)

**В работе, не готово к сдаче.** Обучается собственная политика PPO; есть чекпоинты, но развёрнутой ROS-политики и подтверждённого успешного заезда пока нет. Подробности и воспроизведение — в [TRAINING.md](TRAINING.md).

## I/O

MuJoCo Lowlevel. Политика читает `/cmd_vel` и `/lowstate`, пишет в `/lowcmd_bare`. Только [T2 Safety](../T2/) пишет в `/lowcmd`.

## Текущий статус на 18.11.2026

- В Git есть адаптер Go1 MuJoCo Playground для Brax PPO: актор получает 45 признаков без ground-truth линейной скорости, критик использует привилегированные данные только во время обучения. Команды движения вперёд: 0,1–0,6 м/с.
- Запуск `ppo-v3` на двух T4 использует фильтрацию пределов суставов и шага цели, **без проверки самоколлизий**. Цикл обучения завершил 104 857 600 шагов при запрошенных 80 млн; последняя оценка reward — 33,354. Это не метрика судейского заезда и не подтверждение успеха. Чекпоинты и журналы находятся на T4 в `/kaggle/working/rh-runs/ppo-v3/`, а не в репозитории. [W&B run](https://forge.coreweave.com/wandb/wandb-abreow-abreow/unitree/runs/0kyqsy03).
- Подготовлен экспериментальный CPU callback с проверкой перехода ядром T2. Smoke/parity тест callback прошёл на CPU, но PPO-обучение с ним ещё не запускалось; это не полная эмуляция ROS-узла T2.
