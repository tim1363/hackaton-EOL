# T3 · Ходьба с RL-политикой

**Сдать до 27.11.2026, 12:00 МСК.** [Техническое задание (PDF)](spec.pdf)

**Сделано:** разобран протокол испытаний и зависимость от T2. Политика не выбрана, веса и код запуска пока отсутствуют.

- Вход политики: `/cmd_vel` и `/lowstate`. Выход: `/lowcmd_bare`, затем обязательный [блок защиты T2](../T2/) публикует `/lowcmd`. Среда — MuJoCo Lowlevel.
- Для первого прогона выбрать совместимую политику с разрешённой лицензией, проверить раскладку наблюдений, порядок 12 суставов и частоту инференса. Веса и зависимости должны быть в образе.
- Критерий эпизода: ≥3 м вперёд без падения; 1,5 с прогрева и до 90 с движения по sim time. Сравнить скорости из диапазона 0,1–0,6 м/с и проверить стабильность на 10 независимых стартах.
- После проверки указать выбранную скорость в `ping`. Для бонуса за собственное обучение или дообучение нужны веса, конфигурация и журналы; одного флага `self_trained_rl` недостаточно.
