# T2 · Безопасность низкоуровневого управления

**Сдать до 21.11.2026, 12:00 МСК.** [Техническое задание (PDF)](spec.pdf)

**Сделано:** разобран контракт и составлен план проверки. ROS-узел и алгоритм коллизий ещё не реализованы.

- Вход: `/lowcmd_bare` (`unitree_go/msg/LowCmd`), телеметрия `/lowstate` и `/clock`. Выход: `/lowcmd` ≥50 Гц sim time, без пауз больше 100 мс. В массивах из 20 элементов управляем первыми 12; для позиционного управления нужен `mode=0x0A`.
- Начать с валидатора конечных чисел и углов, ограничения перехода до 5° и таймера по sim time. При пропаже входа в пределах 0,5 с удерживать последнюю принятую цель с нулевыми `dq` и `tau`, не останавливая публикацию.
- Добавить проверку самоколлизий по [модели и списку пар организаторов](https://github.com/Urika000/go1-simulator-public/tree/main/models/mujoco/unitree_go1). Проверять не только конечную позу, но и путь до неё. Judge проверяет переход с шагом до 0,1° и считает проникновение более 1 мм недопустимым.
- Проверить на MuJoCo: пропуск штатной команды, отказ на NaN/Inf, пределы каждого сустава, опасная промежуточная поза, потеря потока и частота выхода под нагрузкой. Этот же блок нужен для [T3](../T3/).
