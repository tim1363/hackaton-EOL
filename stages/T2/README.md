# T2 / Safety

**Дедлайн: 21.11.2026, 12:00 МСК.** [ТЗ (PDF)](spec.pdf)

**В работе, не готово к сдаче.** Ядро проверки целей и коллизий прошло локальные тесты; экспериментальный ROS-узел испытан вместе с T3 в публичном симуляторе. Полная проверка требований T2, упаковка и Judge ещё не выполнены.

## I/O

Читаем `/lowcmd_bare` (`unitree_go/msg/LowCmd`), `/lowstate` и `/clock`. Пишем `/lowcmd` ≥50 Гц по sim time, пауза ≤100 мс. Из 20 элементов массива используем первые 12. Позиционный режим: `mode=0x0A`.

## Реализовано и проверено локально

- `safety_core.py` ограничивает целевые углы и шаг от предыдущей безопасной цели до 5°, отклоняет нечисловые цели и проверяет весь переход. При опасном переходе сохраняется предыдущая цель.
- `CollisionChecker` использует модель MuJoCo и 655 проверяемых пар из `model/`. Сетка проверок включает точки судейской сетки с шагом не более 0,1°; порог с запасом — 0,9 мм проникновения.
- `test_safety_core.py`: тесты ограничений, отклонения столкновений и времени; опциональная проверка совпадения с полной моделью на 1000 случайных конфигурациях прошла с MuJoCo 3.3.7. Это не доказательство корректности на всех позах и переходах.
- В 10 пробных заездах T3 через ROS и публичный MuJoCo наблюдались максимальные паузы `/lowcmd` 32–34 мс по sim time. Это не полный тест частоты, watchdog или всех сценариев T2; подробности — [T3/TRAINING.md](../T3/TRAINING.md).

## Черновик и оставшаяся работа

- Экспериментальный `safety_node.py` использует сообщения Unitree из `vendor/`. Узел подписывается на `/lowcmd_bare` и `/lowstate`, использует sim time, запланирован на 100 Гц и через 0,45 с отсутствия принятой команды удерживает последнюю безопасную цель с `dq=tau=0`. Это намерение реализации, а не измеренные гарантии.

## Локальный тест ядра

В Python-окружении с NumPy и MuJoCo 3.3.7:

```bash
cd stages/T2
python -m unittest -v test_safety_core
# Необязательно: GO1_FULL_SCENE=/путь/к/полной/scene.xml python -m unittest -v test_safety_core
```

Тест без `GO1_FULL_SCENE` пропускает сравнение с полной моделью. Замер времени в тесте информационный и не гарантирует частоту ROS.
